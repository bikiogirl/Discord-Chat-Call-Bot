# 📊 Discord Chat & Call Level Bot

Track your community activity & level up! Earn XP by chatting in text channels and joining voice calls. Compete on the server leaderboards and see who is the most active member!

## ✨ Features

- 💬 **Text Activity Tracking:** Earn XP dynamically by sending messages in text channels.
- 🎙️ **Voice Call XP:** Gain XP automatically for time spent hanging out in voice channels.
- 🏆 **Server Leaderboards:** View real-time rankings for top chatters and top voice participants.
- 👤 **Personal Profiles:** Check your level, current XP, and rank anytime.
- 💾 **Database Integration:** Automatically saves user stats safely using SQLite.

## 🛠️ Commands

| Command | Description |
| :--- | :--- |
| `/profile` | Check your current level, total XP, and activity stats. |
| `/top_chat` | Display the top server leaderboard for text activity. |
| `/top_voice` | Display the top server leaderboard for voice call time. |
